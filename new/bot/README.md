# 会参谋 bot（IM 控制面 / 通知面）

飞书里的"会参谋"机器人：组织者用它指挥会议辅助（入会/审批/收尾），参会者用它申请
接收回答。指令为规则解析，**不进 LLM**；业务全部经 advisor 内部 API（CONTRACT_ADVISOR_API）。

## 用户指令手册

### 组织者（小A）

| 指令 | 说明 |
|---|---|
| `会议列表`（或 `会议`） | 列出近期 7 天内带视频会议链接的日历会议（会议号/时间/是否组织者/是否进行中），可直接复制会议号入会 |
| `入会 <9位会议号>` 或 `入会 <会议链接>` | 开始服务一场会议。首次使用会先收到授权链接，浏览器完成飞书授权后**重发一次**即可 |
| `结束会议 [会议号]` | 停止辅助，云端排空收尾；不带会议号=最近一场进行中的会话 |
| `状态` | 查看各进行中会话的阶段、模型状态与订阅列表 |
| `同意 [编号]` / `拒绝 [编号]` | 审批参会者的订阅申请。**不带编号=最新一条待审批**；带编号（如 `同意 #7`）精确指定 |
| `撤销 [编号]` | 撤销已批准的订阅（对方立即停收）。只有一条时直接撤销；多条会列出编号供选择 |

**关于编号（#N）**：参会者申请订阅时，bot 会私聊你：

> 有参会者申请接收会议《周会》的会参谋回答。
> 回复「同意 #7」或「拒绝 #7」。

`#7` 就是这条申请的编号（全局唯一递增），`状态` 里也能看到（如 `#7 已批准`）。

### 参会者（小B，什么都不用装）

| 指令 | 说明 |
|---|---|
| 任何**包含 9 位会议号或会议链接**的消息（如"我想收到会议 123456789 的信息"） | 向组织者申请订阅该会议的回答；组织者批准后，从**下一条**回答起同时收到（仅前向，不补发历史） |
| `取消订阅 [会议号]`（或 `退订`） | 自助退订；只有一条订阅时不用带会议号 |

订阅被组织者撤销后不可再申请（终态）；被拒绝后可重新申请，会生成新编号走新审批。

### 一次完整流程（示例）

```
小A：会议列表
bot ：《周会》 会议号 123456789 · 11-12 14:00-15:00 · 你是组织者
小A：入会 123456789
bot ：（首次）请点击授权链接完成登录…          ← 浏览器完成授权
小A：入会 123456789
bot ：已入会《周会》，在 laptop 终端粘贴执行：recorder real …
     （另开终端执行该命令，开始听会）
小B：我想收到会议 123456789 的信息
bot →小A：有参会者申请…回复「同意 #7」或「拒绝 #7」
小A：同意
bot ：已批准订阅 #7，之后的回答将同时发送给对方。
小A：结束会议
bot ：正在排空收尾（draining），在途回答发完即结束。
```

## 运维

```bash
pip install -e '.[dev]'
BOT_APP_ID=cli_xxx BOT_APP_SECRET=xxx bot serve --advisor-url http://127.0.0.1:8380
# 本地全栈一键起停见 ../../scripts/local-up.sh（new/docs/LOCAL_TESTING.md）

ruff check src tests && pyright
python -m unittest discover -s tests -v   # 31 项
```

前置：飞书自建应用开通机器人能力、IM 权限、事件订阅（**长连接**方式）订阅
`im.message.receive_v1`；详细配置见 `../../docs/LOCAL_TESTING.md`。

## 边界

- bot 无业务持久状态（重启只影响投递时延）；业务事实都在 advisor。
- 用户消息（含闲聊）不进入会议模型上下文；闲聊/自由问答为 v1 非目标（TODO T2 待评审）。
- 审批请求通知尽力投递；已批准的回答分发走 outbox，可靠（sent/uncertain 语义见契约）。
