## 真实订阅的合成调用

本机 Codex CLI 0.162.0，ChatGPT 订阅登录，默认模型 gpt-6-astra。使用私有临时空目录、ephemeral 线程和合成资料，未使用真实会议数据：

1. 空会议结构化决定返回沉默。
2. 合成参会者的自然语言暂停和恢复分别返回 pause / resume，引用对应字幕句子。
3. 最终通过产品 AdviserRunner 处理合成问题：“已经确认负责人是小林，截止日期是本周五。会参谋，请只根据这两个事实，用一句话总结负责人和截止日期。”真实模型生成包含两个事实的回答，持久化后交给假飞书发送端。
4. 输出统计为 decisions=1、replied=1、model_error=null、fake_api_messages=1；再次运行发送端计数仍为 1。
5. 提交输入前实际枚举线程 MCP 工具，暴露数量为 0。仅对子进程传递配置覆盖，未改写用户全局 Codex 配置或复制登录凭据。

这证明订阅协议、结构化决策与产品发送交接可用；没有验证实际会中可见性、模型回答质量的一般表现或额度上限。

## 会中回归发现的维护锁冲突修复

用户运行 collect 与 consume --watch 时，模型仍在计算且输入持续增加，随后 consume 报 operation or collector already active。代码确认采集每分钟自动维护与消费步骤共用非阻塞维护锁，消费误把短暂占用当作启动冲突退出。

修复为只对共享维护锁进行可中断等待；独立消费者租约仍拒绝第二个消费者。模型完成的结果取得维护锁后才出队，等待不会丢结果。新增三项测试使用真实文件锁覆盖清理占用后继续处理、保存模型结果时争用，以及停止中断等待且输入/会话保留。完整 131 项产品测试通过；实际会议修复后的持续运行仍待用户复测。

## 入会自动核对与显式离会

用户反馈每次 join 前需 reset-session。原代码缓存 joined 后直接返回或拒绝切会，不能发现会议结束后 bot 已不在场。join 现用已保存内部 ID 和当前秒的有界 events 请求核对，120004 自动确认离会再重新入会；仍可访问同一会议时复用；若 bot 仍在另一场会议中，提示先显式 leave，再 join。join 不调用 leave、不更改这时的旧会话。leave 的 121104 会再次核对 bot 缺席，而不将会议状态错误本身当作离会成功。join 在采集或模型消费运行时拒绝切会，避免发送与会话切换并发。

新增测试覆盖旧 bot 缺席、9 位会议号复用且返回新内部 ID、显式 leave 后换会、join 拒绝切会时不发送离会请求且保留旧会话、121104 与会议结束竞态、空页、权限/网络失败保留状态、离会不确定后确认缺席、探测请求范围、运行模型租约保护及自动重入介绍/暂停状态更新。CLI 回归验证提示 leave 后依次执行 leave / join 即可换会，无需 reset-session。旧会议资料保留，入会不确定且缺少内部 ID 时仍需人工核对。自动化验证不代表真实飞书的全部会议结束行为已实测。 完整 143 项产品测试通过，语法和文档链接检查通过。假 app-server 普通协议测试放宽进程启动预算，避免调度抖动误判认证错误；整次截止时间专项测试仍使用原有短预算。

## 间歇性工具错误的诊断改进
