- [ ] **1.3 验收分页、游标与去重。** 已有每页检查点、重启续读、重叠时间窗口及 `sentence_id`/事件 ID 回退键；须依 0.4、0.6 的真实响应核验首次启动、空页、续页、游标过期/失效及转写修订。明确日志写入到状态提交之间崩溃时可能重复，不能承诺 exactly-once 或无漏句。

## 阶段 2：实时问答与验收

- [ ] **2.1 确认首版交互及验收口径。** 与产品确认临时方案“用户明确唤起 + 独立界面文本回答”；**20 秒目标**暂按提问结束到可用回答规划，预算约 15 秒字幕获取 + 5 秒 LLM 生成/输出。明确回答计时终点（首段有效内容还是完整回复）、样本量、中位/P95/最慢样本口径、授权和参与状态展示；不能用字幕片段中位数代表端到端达标。
- [ ] **2.2 接入上下文、唤起与回答。** 支持确认字幕进入上下文、结论修正、暂停/恢复/取消；不被唤起时不回应，内容不足时说明不确定性。
- [ ] **2.3 实测会中延迟与完整性。** 多场获授权会议包含远端发言；标注提问结束、字幕可用、接口请求/返回、Agent 开始有效回答的时刻并说明时钟误差。对比合规轮询间隔下的中位/P95/最大时延与漏句，检查长句、术语和中英混说。
- [ ] **2.4 完成安全和隐私审查。** 明确参会者告知、授权撤销、资料访问、最小化采集、保存期限和删除方式；无权限或无字幕能力时明确报不可用，不静默切换到本地录制。
- [ ] **G2 验收决策。** 依据已确认口径检查准入、无不可解释漏句、**20 秒端到端目标**和隐私要求；若不达标记录字幕生成/轮询/模型各段瓶颈，再决定在 v2 内优化或调整交互/目标，**不启用 v1 + STT**。妙记接口仅考虑经授权的会后核对。
