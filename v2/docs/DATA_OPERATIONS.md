# 产品资料与诊断

产品只读取本机 YAML 中的凭据；不会保存 token、应用密钥或原始 API payload。规范化字幕、说话人及会议/句子标识是敏感资料，保存于私有 `data/source.sqlite3`；产品 session 也在该数据库中，独立于 spike。目录为 `700`，数据库、WAL/SHM 及诊断文件为 `600`。仅支持本机文件系统的 POSIX 锁和 SQLite，不在共享网络盘运行。同一应用共用一个产品数据目录，操作锁在该目录内协调。

默认内容预算 100 MB，SQLite 主库分配预算 150 MB（每个源/假消费者数据库分别限制）；WAL 自动检查点和日志大小限制控制额外占用，`status` 显示主库及侧文件实际大小。这不是整个数据目录的磁盘硬配额；保留足够的磁盘空间。内容、页分配上限或磁盘空间耗尽时事务回滚，检查点不推进；无法落盘的故障由退出码及安全终端提示报告，不伪称诊断已经可靠保存。默认每份诊断最多 1 MB，保留当前文件和 3 份备份，降低配置上限时同步清理超额诊断。

诊断采用字段白名单，仅含状态、错误分类/数字代码、请求标识摘要、请求与处理耗时、重复/修订/冲突计数、积压、容量及时间差汇总。请求标识保存摘要，不保存服务端 msg、正文、参与者、会议 ID、token 或原始查询。每页事务提交后单独记诊断；日志故障不会删除已提交输入。首次出现的字幕/修订候选才进入接收差值统计，重复扫描不重复计样本；回补样本按扫描模式区分。事件接收差值、发言结束至接收差值、最近字幕年龄是三个指标，负值保留以暴露时钟偏差；均不能替代真人说完至看到回答的时延。

默认 7 天为历史记录的可清理门槛。自动维护每分钟检查：只清理超过期限且所有已注册消费者都确认的交付，保护未确认输入、未解决冲突和活动会议恢复/去重状态；过期历史已被裁剪会产生持久化提示。已确认离会、超过期限、全部交付已确认且无未解决冲突的会议可整体清理，其假消费者副本也删除。离会记录按会议保存，切换新会议不丢旧会议的清理依据。

未消费资料与仍需恢复的活动会议状态不会在第 7 天强制丢弃，可能继续占用容量直至消费、离会或显式删除；容量耗尽时停止推进检查点，不能用无声丢弃解决积压。删除中断后，持久化删除标记会在后续维护中继续清理假消费者副本。

从 `v2/` 执行：

```bash
.venv/bin/python -m feishu_meeting_adviser status
# 明确在本机显示最近字幕及说话人；只读，不影响消费进度。
.venv/bin/python -m feishu_meeting_adviser transcripts --show-text
# 手动维护前先停止采集；正常采集会自动维护。
.venv/bin/python -m feishu_meeting_adviser prune
# 默认只列未解决候选的交付哈希；下条命令明确在本机显示候选正文。
.venv/bin/python -m feishu_meeting_adviser conflicts
.venv/bin/python -m feishu_meeting_adviser conflicts --show-text
.venv/bin/python -m feishu_meeting_adviser resolve-conflict --delivery-id <候选交付哈希>
# 显式删除当前保存会议的输入、消费进度和所有托管假消费者副本，不可恢复。
.venv/bin/python -m feishu_meeting_adviser delete-meeting-data --confirm
```

显式删除不受“未确认”保护规则限制；产品保留必要的 bot 控制 session，以便显式离会，但已删除会议不能自动重采。删除标记只保存会议标识摘要与删除时间，不保存正文。SQLite 启用安全删除并在显式删除后压缩/截断 WAL；这是应用数据清理，不承诺存储介质物理擦除。手动备份、终端正文、其他自建消费者和 spike 的 `output/` 不属于产品托管副本，应另行按授权清理。撤销授权时先停止采集，按需要显式离会并删除资料。
