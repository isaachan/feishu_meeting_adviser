# 飞书实时会议 AI 助理

项目目标是在会议进行时获取讨论内容并提供 AI 辅助；会后逐字稿不能代替会中输入。**当前产品决策：只继续 v2 官方会中字幕路线；v1 已放弃，不作为自动或人工回退方案。**历史代码保留供查阅，不代表仍在开发。

- **[v1](v1/README.md)**：历史方案，读取录制中的本地 `.vemedia` 文件、提取音频并用流式 STT 转写。虽然获取文字可能更快，但缺少可靠的说话人信息，会议上下文太弱，**已明确放弃**；代码及历史文档仅保留存档，不再用于本产品回退。
- **[v2](v2/README.md)**：新方案，优先验证已入会应用机器人以应用身份获取会中字幕（轮询 `bots/events` 的 `transcript_received`）。应用身份入会、单次字幕读取及一次会中持续采集与双人脚本对照已试通；旧试验代码已隔离到 `v2/reference/spike/`，产品代码从 `v2/src/feishu_meeting_adviser/` 重新实现，仍待验证增量完整性与异常恢复；问答尚未实现。不达标时记录问题并调整 v2 产品/技术方案，不切回 v1。

**原 6 秒目标已撤销。新的规划目标为 20 秒**：约 15 秒取得会中字幕，约 5 秒由 LLM 生成/输出回答；从提问结束到可用回答的精确计时终点及统计口径仍待确认。一场测试中字幕片段从接口结束时间到本机接收的中位数约 15 秒、最大约 24 秒，因此 20 秒**是预算，不是已实现的 SLA**。`v1/material/` 和 `v2/output/` 可能包含敏感会议资料；请按授权范围使用，不要将本地模型、虚拟环境或实验产物提交到仓库。`v1/venv/` 随目录迁移后可能含旧绝对路径，若无法使用，请在 `v1/` 重新创建虚拟环境。
