# 飞书实时会议 AI 助理

项目目标是在会议进行时获取讨论内容并提供 AI 辅助；会后逐字稿不能代替会中输入。两个版本是**不同的技术路线**，不是已上线版本与已完成升级版。

- **[v1](v1/README.md)**：旧方案，读取录制中的本地 `.vemedia` 文件、提取音频并用流式 STT 转写。原有代码、测试、文档、依赖和本地实验材料均在 `v1/`，供复现与备选；历史结论按当时记录保留。运行命令请先进入 `v1/`。
- **[v2](v2/PLAN_OFFICIAL_MEETING_EVENTS.md)**：新方案，优先验证飞书用户身份接口获取会中字幕（轮询 `bots/events` 的 `transcript_received`）。目前是待核验的计划，接口权限、会议设置、增量游标和真实时延都需要实测；未完成代码实现。若不可用或不达标，再评估 v1 输入路线。

两条路线均以会中问答为目标；已确认的端到端目标是从提问结束到开始有效回答 **6 秒**，具体验收口径仍须确认。`v1/material/` 可能包含敏感会议资料；请按授权范围使用，不要将本地模型、虚拟环境或实验产物提交到仓库。`v1/venv/` 随目录迁移后可能含旧绝对路径，若无法使用，请在 `v1/` 重新创建虚拟环境。
